## Aplikasi Kasir dengan PHP, My SQL

## 1. Kebutuhan Software & Persiapan

Silakan unduh dan instal software berikut jika belum ada di komputer/server Anda:

- **Git** (untuk clone repositori): https://git-scm.com/
- **XAMPP** (Untuk menjalankan PHP & Apache): https://www.apachefriends.org/
- **Visual Studio Code** (Code Editor): https://code.visualstudio.com/

# Cara Download:

1. Buka Terminal (Command Prompt / PowerShell / Terminal di VS Code) dan arahkan ke folder
```cmd
cd C:\xampp\htdocs\
```
2. clone repositori dengan perintah cmd di bawah ini
```cmd
https://github.com/muhammadedlinperkasaalam/kasir.git
```
